# Use Cases (informative)

***This section answers:*** *What does it look like in practice? — Worked use cases that
exercise the six domains, the Verifiability Tiers, and the System surface against real
deployments.*

> **[DRAFT] — to be developed by the working group.** This section will hold worked examples
> that exercise the six domains ([C1 to C6](../0.1/en/0x10-C01-Provenance.md)), the System
> surface ([C9](../0.1/en/0x10-C09-System-Surface-MAESTRO.md)), and the Verifiability Tiers
> ([C8](../0.1/en/0x10-C08-Verifiability-Tiers.md)) against real agent deployments, so a reader
> can see how a Proof-of-Control claim is made and checked in practice. The working group will
> contribute and prioritize the use cases; it is intentionally left open here for that input.
> Each use case will state not only what Proof-of-Control verifies but what it does not verify
> in that deployment (for example, that a sanctions list was correctly compiled, or that a
> consent record was validly obtained), keeping the verification-not-validation boundary
> ([C1 to C6](../0.1/en/0x10-C01-Provenance.md)) concrete against real examples.

**First worked use case:** Proof-of-Control for the Universal Commerce Protocol, adapting Ken
Huang's UCP assurance framework, which exercises the six domains, the System surface, and the
Verifiability Tiers against a live agentic-commerce protocol. It lives in the companion demo
document, "UCP PoC Demo." <!--aais-allow-->
